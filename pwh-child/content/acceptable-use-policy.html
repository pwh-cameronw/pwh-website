6. Excessive Resource Usage

6.1. CloudLinux CPU core, RAM allocations, I/O usage, Processes and inodes count limits apply to all shared cPanel and/or Plesk (Odin) web hosting Services, including Legacy Services. Any Service which exceeds these limits will automatically display a “503 Service Temporarily Unavailable” message to all visitors until the resource usage falls below the assigned limits.

6.2. For all shared cPanel and/.or Plesk (Odin) web hosting Services and Legacy Services, the Customer may not:

  1. Perform any task which unreasonably consumes server resources leading to degradation of the shared hosting server environment for other Customers;
  2. Consistently utilise the resource allocations as set within CloudLinux to a level at or near to complete utilisation for any singular resource type;
  3. Perform any task which generates excessive IO load;
  4. Consume large amounts of system memory;
  5. Consume more than the allocated inode limit assigned to the Service, where 1 file equals 1 inode;
  6. Execute a script which takes longer than 300 seconds to complete;
  7. Operate a script which does not close MySQL connections upon completion;
  8. Run any server-side or stand-alone processes or daemons;
  9. Run cron entries with intervals less than 15 minutes;
  10. Use PHP includes that call the full URL instead of a local file (eg. include(http://domainname.com/file.php) instead of using include(“file.php”));

6.3. For all VPS Services, the Customer:

  1. May not have a sustained network throughput (in or out) of more than 10Mbit/s over 300 seconds;
  2. Should ensure that they have sufficient physical memory to run all applications and does not continuously use swap space, which causes high IO consumption.

6.4. Perth Web Hosting reserves the right to suspend any Service(s) utilising excessive network resources, and reserves the right to charge excessive usage fees for excessive usage. Perth Web Hosting may make reasonable attempts to notify the Customer at the time of suspension, however, notification is not guaranteed and the Customer should ensure they are compliant with all policies at all times.

6.5. Exemptions to elements of our Excessive Resource Usage policy may be granted on a case-per-case basis in consultation with our management team. For further information, or to request exemption to specific elements, please contact our support team.
