# Images

Run `FIGMA_TOKEN=… python3 tools/fetch-figma-assets.py` from the theme folder to fill this folder from Figma:

- `hero-laptop.png` – hero photo (laptop)
- `card-domains.png`, `card-hosting.png`, `card-email.png` – product cards
- `why-pwh.png` – "Not sure what you need?" background
- `not-sure-cta.png` – "Feeling a bit lost?" photo
- `avatar-placeholder.png` – testimonial avatar
- `logo-light.png` – footer logo
- `logo-dark.svg` – header logo
