# Fonts

The display face in the design is **GT Standard M Extended** (Grilli Type, commercial licence).
Add your licensed web font files here with exactly these names:

| File | Weight | Used for |
| --- | --- | --- |
| `GT-Standard-M-Extended-Black.woff2` | 900 | H1, H2, H3, card titles |
| `GT-Standard-M-Extended-Bold.woff2` | 700 | Eyebrow labels |

Until they are added, headings fall back to **Archivo Expanded** (Google Fonts), which is close in width and weight.
Body text uses **Inter** from Google Fonts. Nothing else to set up.
